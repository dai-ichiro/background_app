# Background App (シリアル通信キー入力自動化ツール)

このアプリケーションは、指定されたシリアルポート（COMポート）をバックグラウンドで監視し、受信したデータに基づいて事前に定義されたキー操作（キーストローク）を自動的に実行します。タスクトレイに常駐し、タスクバーには表示されません。

## 機能

*   **バックグラウンド実行**: アプリケーションは最小化状態で起動し、タスクバーには表示されません。タスクトレイのアイコンから終了操作が可能です。
*   **設定ファイルによるカスタマイズ**: `key_config.json` ファイルを使用して、監視するCOMポートや、受信データに対するキー操作のアクションを柔軟に定義できます。
*   **アクションの自動実行**: シリアルポートからデータを受信すると、設定された一連のキー入力や待機処理（ウェイト）を自動的に実行します。
*   **ログ出力**: `logging_enabled` を有効にすることで、動作状況やエラー情報を `debug.log` に記録できます。

## 必要要件

*   Windows OS
*   .NET Framework 4.8

## インストールとセットアップ

1.  ビルド済みの実行ファイル (`background_app.exe`) と設定ファイル (`key_config.json`) を同じフォルダに配置します。
2.  `key_config.json` を環境に合わせて編集します（COMポート番号など）。

## 設定 (Configuration)

設定は `key_config.json` ファイルで行います。

### key_config.json の例

```json
{
  "settings": {
    "com_port": 3,              // 使用するCOMポート番号 (例: 3 -> COM3)
    "logging_enabled": false    // ログ出力の有効化 (true: 有効, false: 無効)
  },
  "actions": {
    "1": [                      // シリアルポートから受信したデータ（文字列）をキーとします
      {
        "type": "key",          // キー入力アクション
        "value": "Alt"          // 入力するキー (例: Alt, Ctrl+C, A)
      },
      {
        "type": "wait",         // 待機アクション
        "value": "300"          // 待機時間 (ミリ秒)
      },
      {
        "type": "key",
        "value": "H"
      }
    ]
  }
}
```

### 設定項目の説明

#### settings
*   `com_port`: 接続するシリアルポート番号を指定します（整数）。
*   `logging_enabled`: `true` に設定すると、アプリケーションと同じディレクトリに `debug.log` が生成され、動作ログが記録されます。

#### actions
受信データ（文字列）をキーとし、そのデータを受信した際に実行するアクションのリストを定義します。

各アクションステップは以下の形式で記述します：
*   `type`:
    *   `"key"`: キーボード入力をシミュレートします。
    *   `"wait"`: 指定時間待機します。
*   `value`:
    *   `type` が `"key"` の場合: 入力するキーを指定します。従来の SendKeys ではなく、より安定した SendInput API を使用します。キー名は `System.Windows.Forms.KeysConverter` で解析可能な一般的な英語名を使用します。
        *   例: `Ctrl+C` (Ctrl+C), `Enter` (Enterキー), `Alt` (Altキー), `A` (Aキー)
    *   `type` が `"wait"` の場合: 待機時間をミリ秒単位で指定します（整数）。


## 使い方

1.  `background_app.exe` を実行します。
2.  アプリケーションは自動的に設定されたCOMポートを開き、待機状態になります。
3.  外部デバイスからシリアル通信で定義済みのデータが送信されると、PC上で自動的にキー入力が行われます。
4.  アプリケーションを終了するには、タスクトレイにあるアイコンを右クリックし、「終了」を選択してください。

## トラブルシューティング

*   **動作しない場合**:
    *   `key_config.json` の `logging_enabled` を `true` に設定し、再起動してください。
    *   生成される `debug.log` ファイルを確認し、COMポートの接続エラーや設定ファイルの読み込みエラーが発生していないか確認してください。
    *   COMポートが他のアプリケーションで使用されていないか確認してください。
